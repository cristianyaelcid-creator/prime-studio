Preguntas frecuentes

Antes de comenzar, aclaramos tus dudas.

¿Cómo funciona el pago único?

Pagas una vez por el diseño y desarrollo acordado. No significa que el dominio, hosting o servicios externos sean gratuitos para siempre.

¿La suscripción es obligatoria?

No. El mantenimiento mensual es opcional. Puedes contratar únicamente el desarrollo de tu proyecto.

¿Puedo tener mi propio dominio?

Sí. Podemos orientarte para registrar una dirección personalizada. El dominio debe renovarse según las condiciones del proveedor.

¿Las páginas funcionan en celulares?

Sí. Los proyectos web se diseñan para adaptarse a diferentes tamaños de pantalla.

¿Puedo solicitar cambios?

Se acuerdan las revisiones incluidas antes de comenzar. Cambios adicionales o funciones nuevas pueden tener un costo extra.

¿Cuánto tarda un proyecto?

Depende del tipo de servicio, la cantidad de contenido y las revisiones necesarias. El plazo se confirma antes de iniciar.
